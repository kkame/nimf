Nimf APT Repository

Ubuntu 24.04 / 26.04 및 Debian 12 / 13에서 apt로 간편하게 설치하고 자동 업그레이드할 수 있는 kkame/nimf 공식 패키지 저장소입니다. GNOME Wayland 네이티브 앱과 Electron(Slack, Orca 등), JetBrains IDE를 모두 지원합니다.

1 APT 저장소 등록 및 설치

최초 1회 GPG 키와 APT 저장소(DEB822 형식)를 등록하면, 이후부터는 sudo apt upgrade로 최신 버전이 자동 업데이트됩니다.

bash · DEB822
# 1. GPG 서명 키 등록
curl -fsSL https://kkame.github.io/nimf/gpg.key | sudo gpg --dearmor --yes -o /usr/share/keyrings/kkame-nimf.gpg

# 2. APT 저장소 등록 (Ubuntu 24.04 noble / 26.04 resolute / Debian bookworm·trixie 자동 감지)
sudo tee /etc/apt/sources.list.d/kkame-nimf.sources > /dev/null <<EOF
Types: deb
URIs: https://kkame.github.io/nimf
Suites: $(. /etc/os-release && echo "$VERSION_CODENAME")
Components: main
Architectures: $(dpkg --print-architecture)
Signed-By: /usr/share/keyrings/kkame-nimf.gpg
EOF

# 3. Nimf 설치 (다국어 엔진 포함 시 nimf-i18n 함께 설치)
sudo apt update
sudo apt install -y nimf nimf-i18n

# 4. 기본 입력기 지정 후 재로그인
im-config -n nimf

환경 변수 및 im-config 설정까지 한 번에 자동으로 구성하고 싶을 때 사용하세요. (Wayland 세션에서는 ibus-daemon을 자동으로 유지합니다.)

bash · Quick Install
curl -fsSL https://raw.githubusercontent.com/kkame/nimf/master/install | sudo bash

APT 저장소가 등록된 상태에서는 일반 시스템 업데이트와 동일하게 관리할 수 있습니다.

bash · Manage
# 최신 버전 업그레이드
sudo apt update && sudo apt upgrade -y nimf nimf-i18n

# 패키지 및 저장소 완전 제거
sudo apt remove -y nimf nimf-i18n
sudo rm -f /etc/apt/sources.list.d/kkame-nimf.sources /usr/share/keyrings/kkame-nimf.gpg
sudo apt update

2 지원 배포판 및 주요 개선 사항

Ubuntu / Debian APT 지원

amd64 및 arm64 아키텍처용 GPG 서명 패키지를 제공합니다.

resolute (26.04) noble (24.04) trixie (13) bookworm (12)

GNOME Wayland 네이티브 지원

libnimf-wayland에 내장된 zwp_text_input_v3/IBus D-Bus 브릿지로 Slack, Orca, JetBrains IDE에서도 X11 강제 전환 없이 한글 입력이 동작합니다.

Wayland XKB 옵션 설정

nimf-settings가 Wayland에서도 evdev.xml을 직접 읽어 한/영·한자 키 등 XKB 옵션을 바로 설정할 수 있습니다.
